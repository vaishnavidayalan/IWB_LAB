# 💜 Professional Registration Form

A responsive and user-friendly registration form developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

## Features

- Modern light-purple gradient design
- Responsive Bootstrap layout
- Glassmorphism-style registration card
- Full name validation
- Email validation
- Phone number validation
- Password validation
- Password confirmation
- Password strength indicator
- Show/hide password option
- Terms and Conditions checkbox
- Error messages for invalid input
- Registration success message
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Form Fields

The form contains the following fields:

1. Full Name
2. Email Address
3. Phone Number
4. Password
5. Confirm Password
6. Terms & Conditions

## Validation

JavaScript validates the user input before registration.

### Name
The name must contain only alphabetic characters and spaces.

### Email
The email must follow a valid email format.

### Phone
The phone number must contain exactly 10 digits.

### Password
The password must contain at least 8 characters.

The password strength indicator checks for:

- Minimum length
- Uppercase letters
- Numbers
- Special characters

### Confirm Password
The confirmation password must match the password.

### Terms and Conditions
The user must accept the Terms & Conditions before registration.
